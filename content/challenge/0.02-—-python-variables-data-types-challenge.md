Build a small Python program that stores and displays different types of information using variables.

This challenge is designed for absolute beginners and introduces strings, integers, floating-point numbers, booleans, formatted output, and basic type conversion.

You’ll start with simple variables and gradually turn them into a small interactive profile program that accepts user input and displays the information in a clean format.

The goal is to understand how Python stores and works with data before moving on to calculations, conditions, and larger programs.
