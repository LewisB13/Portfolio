I built a Number Guessing Game using Python as part of my learning journey. The player chooses a difficulty level and tries to guess a randomly generated number within a limited number of attempts.

The game provides higher or lower hints after each guess and keeps track of the attempts remaining. I also added separate high scores for Easy, Medium, and Hard difficulties, which are saved to a text file so they are remembered after the program is closed.

After building the main game in the terminal, I created a simple graphical user interface using Tkinter. This project helped me practise Python fundamentals including functions, conditionals, dictionaries, random number generation, input validation, file handling, exception handling, and basic GUI development.
