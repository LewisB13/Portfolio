Build a classic Rock Paper Scissors game in Python where the player competes against the computer.

Start by allowing the player to choose Rock, Paper, or Scissors while the computer randomly selects its own choice. Compare both choices, determine the winner, and keep track of the score across multiple rounds.

Once the core game is working, build a basic GUI that allows the player to make their choice using buttons and see the computer’s choice visually.

The goal of this challenge is to bring together Python fundamentals such as variables, conditions, randomisation, functions, game logic, and user interaction into a small but complete playable project.
