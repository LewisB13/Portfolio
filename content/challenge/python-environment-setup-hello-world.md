Set up a complete Python development environment and run your first program.

This challenge is designed for absolute beginners with zero programming experience. The goal is to get the essential tools installed, understand the basic development setup, and successfully run a simple Python program from the terminal.

By the end of the challenge, you should have Python and a code editor installed, a dedicated project folder created, and a working `Hello World` program that you can run from the command line.

Keep it simple. There’s no need to understand everything yet — the objective is to get your environment working and become comfortable with the basic process of creating and running Python code.
