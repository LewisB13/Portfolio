# Self-Hosted File Synchronisation Using Syncthing

## Project Overview

In this home lab, I installed and configured Syncthing directly on Windows to explore secure, peer-to-peer file synchronisation without relying on traditional cloud storage services.

The project focused on understanding self-hosted applications, device connectivity, file management, and network-based synchronisation.

## Project Objectives

- Install and configure Syncthing on Windows.
- Explore peer-to-peer file synchronisation.
- Understand device pairing and folder sharing.
- Learn how synchronisation services communicate across networks.
- Develop practical troubleshooting and administration skills.

## Tools & Technologies

- Windows 10 Enterprise
- Syncthing
- TCP/IP Networking
- Syncthing Web Interface

## Implementation

### 1. Installation & Setup

Installed Syncthing directly on Windows and accessed its web-based management interface to configure the application.

### 2. Device Management

Explored Syncthing's device identification and pairing functionality, including how trusted devices are authorised to communicate.

### 3. Folder Configuration

Reviewed folder sharing settings and how Syncthing manages synchronisation between connected devices.

### 4. File Synchronisation

Explored how Syncthing securely transfers and synchronises files between devices using peer-to-peer connections.

### 5. Monitoring & Troubleshooting

Used the Syncthing interface to review device connectivity, folder status, and available troubleshooting information.

## Project Outcome

Successfully installed and configured a self-hosted Syncthing environment, gaining practical experience with file synchronisation, application configuration, and peer-to-peer networking.

## Skills Demonstrated

- Windows application administration
- Peer-to-peer networking
- File synchronisation
- Device and folder management
- Self-hosted service configuration
- IT troubleshooting
- System administration fundamentals

## Future Improvements

- Test synchronisation between additional devices.
- Configure file versioning and recovery.
- Explore automated startup and background services.
- Improve monitoring and access security.

## Conclusion

This project strengthened my understanding of self-hosted file synchronisation, Windows application management, and network-based services. The skills gained are relevant to IT Support, Desktop Support, and System Administration roles.
