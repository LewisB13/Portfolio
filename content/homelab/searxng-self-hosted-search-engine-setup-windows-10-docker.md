# Self-Hosted SearXNG Search Engine Using Docker

## Project Overview

In this home lab, I deployed SearXNG, an open-source, privacy-focused metasearch engine, using Docker. The aim of this project was to gain hands-on experience with containerisation, self-hosted applications, and basic service management.

SearXNG aggregates search results from multiple search engines, providing a customisable search experience with an emphasis on user privacy.

## Project Objectives

- Deploy a self-hosted application using Docker.
- Gain practical experience with containerisation.
- Understand how Docker containers run and manage applications.
- Explore basic application configuration and networking.
- Develop troubleshooting skills for containerised services.

## Tools & Technologies

- **Docker:** Container deployment and management.
- **SearXNG:** Open-source metasearch engine.
- **Docker Compose:** Multi-container configuration and deployment, if applicable.
- **Web Browser:** Accessing and testing the deployed service.

## Implementation

### 1. Environment Preparation

Prepared the Docker environment and obtained the necessary SearXNG container image and configuration files.

### 2. Container Deployment

Deployed SearXNG inside a Docker container, allowing the application to run in an isolated environment without requiring a traditional installation directly on the host operating system.

### 3. Application Configuration

Explored SearXNG configuration options and Docker networking, including how container ports allow access to services through a web browser.

### 4. Functionality Testing

Accessed the self-hosted SearXNG interface through a web browser and tested search functionality to verify that the application was operating correctly.

### 5. Service Management

Practised basic Docker container management, including checking container status and understanding how container logs can assist with troubleshooting.

## Project Outcome

Successfully deployed a self-hosted SearXNG instance using Docker, gaining practical experience with containerised application deployment and service management.

The project demonstrated how Docker can simplify application deployment and provide a consistent environment for running self-hosted services.
